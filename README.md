# 🍔 Telegram Food Order Bot

A simple Telegram food ordering bot built with Python and Aiogram.

---

## 🚀 Features
```bush
✅ Food menu with inline buttons
✅ Add products to cart
✅ View cart
✅ Order confirmation system
✅ User information collection
✅ Send orders to admin
✅ FSM (Finite State Machine) support
✅ Aiogram 3.x support
```
---

## 🛠 Technologies Used

* Python
* Aiogram 3.x
* FSM
* Asyncio

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Open project folder:

```bash
cd YOUR_REPOSITORY
```

Install requirements:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run The Bot

```bash
python bot.py
```

---

## 📋 Bot Functions

### 📋 Menu

Users can view available foods:

* 🍕 Pizza
* 🍔 Burger
* 🥤 Cola

### 🛒 Cart

Users can:

* Add items
* View selected products

### 🚀 Order System

The bot asks for:

* User name
* Address

Then sends the order to admin.

---

## 📸 Example Workflow

1. Start the bot
2. Open menu
3. Add food to cart
4. Enter name & address
5. Confirm order
6. Admin receives the order
